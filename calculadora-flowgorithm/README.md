## Objetivo

Desenvolver uma calculadora utilizando o **Flowgorithm**, permitindo ao usuário selecionar diferentes operações matemáticas e situações que envolvem lógica de programação.

O projeto contempla **20 operações**, incluindo as funções obrigatórias de **cálculo do IMC** e **cálculo de área de figuras geométricas**.

## Descrição

A calculadora apresenta ao usuário um **menu com 20 opções de cálculo**. Após selecionar uma operação, o programa solicita os dados necessários, realiza o processamento das informações e apresenta o resultado correspondente. O fluxograma foi estruturado de forma organizada, buscando facilitar a compreensão do funcionamento do algoritmo e a interação com o usuário.

## ⭐ Funções Obrigatórias

### IMC — Índice de Massa Corporal

A calculadora possui uma função específica para calcular o **Índice de Massa Corporal (IMC)** a partir do peso e da altura informados pelo usuário.

**Fórmula utilizada:**

```text
IMC = peso / (altura × altura)
```

Após o processamento, o programa apresenta o resultado calculado.

### Área de Figuras Geométricas

O projeto contempla o cálculo de áreas geométricas por meio das seguintes operações:

* **Área do Quadrado**
* **Área do Retângulo**
* **Área do Triângulo**
* **Área do Círculo**

Cada operação solicita as medidas necessárias e realiza o cálculo correspondente.

## ▶️ Como Executar

Para executar o projeto, é necessário ter o **Flowgorithm** instalado no computador.

1. Baixe ou clone este repositório.
2. Abra o arquivo `calculadora.fprg`.
3. Execute o arquivo utilizando o Flowgorithm.
4. Selecione uma das 20 opções disponíveis no menu.
5. Informe os valores solicitados pelo programa.
6. Visualize o resultado da operação escolhida.
